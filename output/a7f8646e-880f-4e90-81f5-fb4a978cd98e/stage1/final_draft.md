# 臻冰柱与寒霜状态系统策划案

## 一、系统概述

### 1.1 设计目标

本系统围绕「臻冰柱」这一核心场景物件，构建一条单向递进的寒霜状态链，并通过「臻冰棒」武器与「西岭青」饮品提供两套反向干预手段：前者将负面状态向深层推进，后者将负面状态转化为正面增益。整体形成「施加负面 → 加深负面 → 打断或逆转」的完整博弈闭环。

### 1.2 核心状态链

寒冷、落霜、冻结三者构成一条**单线互斥链**：同一时刻，任一生物身上只能存在其中一种状态，不可并存、不可跨级叠加。状态只能沿「寒冷 → 落霜 → 冻结」单向递进。

```
臻冰柱 → 寒冷 →（3 秒）→ 落霜 →（臻冰棒）→ 冻结
```

配套逆转链：

```
寒冷 / 落霜 / 冻结 →（饮用西岭青）→ 归煦 →（归煦结束）→ 温暖 / 化霜 / 消融
```

### 1.3 文档约定

- 时间单位「刻」为 Minecraft 标准游戏刻（20 刻 = 1 秒）。
- 「范围」「半径」等空间参数如无特别说明，均以方块为单位。
- 本文所列数值为初始设计值，可在实装调试阶段微调。

---

## 二、臻冰柱

臻冰柱是本系统的场景核心，负责在范围内施加寒霜状态并熄灭火焰。

### 2.1 基础行为

| 行为 | 规则 |
|------|------|
| 火焰熄灭 | 臻冰柱范围内的火焰熄灭 |
| 施加寒冷 | 生物进入范围即施加「寒冷」状态 |
| 状态转化 | 处于寒冷状态 3 秒后，转化为「落霜」 |
| 落霜刷新 | 已带「落霜」的生物再次进入范围，刷新落霜计时（仅重置时长，不叠加层数） |

### 2.2 交互要点

- 「进入范围施加寒冷」与「落霜刷新」是两条独立判定：首次进入走施加逻辑，携带落霜再次进入走刷新逻辑。
- 落霜的刷新为**时长重置**，不会提高落霜等级或加快后续递进，避免无限叠加导致的强度失控。

---

## 三、负面状态详解

### 3.1 寒冷

寒冷是状态链的第一级，以感官与数值削弱为主。

- **移动速度**：降低生物移动速度。
- **冻伤易伤**：生物受到的冻伤伤害增加。
- **限制**：寒冷仅为感官与数值效果，本身**无法实际灭火**。

### 3.2 落霜

落霜是状态链的第二级，在寒冷基础上增加粒子表现与递进式减速。

- **基础效果**：与寒冷同理（减速、冻伤易伤）。
- **视觉表现**：新增雪花粒子持续掉落。
- **递进减速**：每 25 刻降低一次移动速度。
- **减速下限**：当本状态造成的累计移速降低达到 15%（即降低量 ≤ 15% 的判定边界）时，停止继续降低。
- **平滑恢复**：落霜被移除后，移动速度以与降低时相同的速率逐刻恢复。
- **HUD 提示**：在移速降低的同时，缓慢显示冻伤的 HUD 纹理。

> 数值说明：减速「速率」与「上限」为两个独立参数——每 25 刻降低固定幅度，累计降幅触顶后不再下降，恢复时按同一固定幅度逐级回调。

### 3.3 冻结

冻结是状态链的第三级，也是最深层负面状态。

- **基础效果**：与落霜同理（减速、雪花粒子、HUD 纹理）。
- **周期伤害**：每 40 刻掉落冰块粒子，并造成 1 点冻伤伤害。
- **生命纹理**：生命值显示为青蓝色冻结纹理。
- **躯体表现**：生物身体出现颤抖效果。
- **火焰交互**：可熄灭着火生物的火焰。
- **伤害减免**：可减少部分岩浆与火焰类型造成的伤害。

## 四、环境交互

环境交互为状态链提供外部的施加、解除与伤害入口。

| 状态 | 环境条件 | 结果 |
|------|---------|------|
| 寒冷 | 处于水中 | 移动速度降低 |
| 寒冷 | 接近火源 | 移除寒冷状态 |
| 落霜 | 接触水 | 受到一次冻伤伤害，并移除落霜状态 |

### 4.1 设计意图

- 水对寒冷与落霜的作用相反：水强化寒冷（减速），却打断落霜（冻伤 + 移除），形成「以水破霜、以火破寒」的对策关系。
- 火源仅能解除第一级「寒冷」，无法解除更深层的落霜与冻结，突出状态递进的解法差异。

---

## 五、火焰与伤害减免

| 状态 | 熄灭着火生物火焰 | 减免岩浆/火焰伤害 |
|------|----------------|------------------|
| 寒冷 | 否 | 否 |
| 落霜 | 是 | 否 |
| 冻结 | 是 | 是（部分） |

- 灭火能力从落霜开始解锁，寒冷不具备灭火能力。
- 伤害减免仅在冻结层生效，且为「部分减免」而非完全免疫。

---

## 六、物品相关

### 6.1 霜冻辣椒

- **效果**：食用后获得「寒冷」状态。
- **定位**：可携带的寒冷施加道具，用于主动触发状态链起点。

### 6.2 臻冰棒

臻冰棒是本系统的主动进攻武器，兼具范围控制与状态推进功能。

- **击碎臻冰柱**：可攻击臻冰柱使其破碎。
  - 破碎造成范围冻伤伤害。
  - 破碎造成范围减速。
- **状态推进**：攻击携带「落霜」的生物时，为其施加「冻结」状态，并移除其「落霜」。
  - 该过程严格遵循单线互斥：落霜被冻结取代，而非并存。

---

## 七、玩家适用性

- 玩家同样能够接受臻冰柱施加的「寒冷」与「落霜」状态。
- 玩家不受豁免，需与生物遵循同一套状态规则（包括减速、易伤、粒子与解除条件）。
- 该设定保证机制对玩家与生物一致，避免规则割裂。

---

## 八、西岭青与归煦

### 8.1 西岭青

- **效果**：饮用后获得「归煦」状态。
- **定位**：本系统的核心逆转道具，将负面状态链整体翻转为正面增益链。

### 8.2 归煦

归煦是状态逆转的过渡态，负责即时转化与免疫保护。

| 特性 | 规则 |
|------|------|
| 即时转化 | 获得归煦的瞬间，立即将已有的寒冷 / 落霜 / 冻结转化为对应的正面效果 |
| 生命表现 | 转化瞬间生命值泛暖光 |
| 期间免疫 | 归煦持续期间，免疫新的寒冷 / 落霜 / 冻结施加 |
| 独立计时 | 归煦结束后，转化出的正面效果拥有独立持续时长，从归煦结束时开始计算 |

### 8.3 正面效果详解

#### 8.3.1 温暖（由寒冷转化）

- **移动速度**：提升生物移动速度。
- **伤害转化**：将受到的伤害恢复为等量生命值。

#### 8.3.2 化霜（由落霜转化）

- **递进加速**：每 25 刻提升一次移动速度，最高提升 +15%。
- **纹理消退**：生命纹理从边缘开始消退。
- **平滑回落**：化霜被移除后，移动速度按提升速率逐刻平滑回落。

#### 8.3.3 消融（由冻结转化）

- **周期回复**：每 40 刻回复 1 点生命。
- **溢出转化**：生命值已满时，回复量转为临时生命。
- **免疫**：不再受到冻伤和细雪影响。
- **环境交互**：触碰可融化细雪。

## 九、机制总览

### 9.1 状态转换全景

```
【负面推进】
臻冰柱 → 寒冷 →（3 秒）→ 落霜 →（臻冰棒）→ 冻结
（三者单线互斥；携带落霜再次进入臻冰柱仅刷新计时）

【正面逆转】
寒冷 / 落霜 / 冻结 →（饮用西岭青）→ 归煦
归煦结束 → 温暖 / 化霜 / 消融（各自独立计时）
```

### 9.2 状态能力矩阵

| 状态 | 层级 | 减速 | 周期伤害 | 灭火 | 火焰减伤 | 特殊 |
|------|------|------|---------|------|---------|------|
| 寒冷 | 负面 1 | 基础减速 | 无 | 否 | 否 | 水中减速；接近火源移除；冻伤易伤 |
| 落霜 | 负面 2 | 每 25 刻递减，累计上限 15% | 无 | 是 | 否 | 雪花粒子；HUD 渐显；接触水→冻伤+移除 |
| 冻结 | 负面 3 | 同落霜 | 每 40 刻 1 点冻伤 | 是 | 部分 | 青蓝生命纹理；身体颤抖；冰块粒子 |
| 温暖 | 正面 1 | 提速 | 无 | — | — | 伤害转等量生命 |
| 化霜 | 正面 2 | 每 25 刻递增，上限 +15% | 无 | — | — | 纹理边缘消退；移除后平滑回落 |
| 消融 | 正面 3 | — | 无 | — | — | 每 40 刻回 1 血，满血转临时生命；免疫冻伤/细雪；融化细雪 |

### 9.3 对策关系速查

| 手段 | 作用对象 | 效果 |
|------|---------|------|
| 火源 | 寒冷 | 移除寒冷 |
| 水 | 寒冷 | 减速（强化负面） |
| 水 | 落霜 | 冻伤伤害 + 移除落霜 |
| 臻冰柱 | 落霜 | 刷新落霜计时 |
| 臻冰棒 | 落霜 | 施加冻结并移除落霜 |
| 臻冰棒 | 臻冰柱 | 击碎，范围冻伤 + 减速 |
| 西岭青（归煦） | 任意负面 | 即时转化为正面，期间免疫 |
| 霜冻辣椒 | 任意生物 | 施加寒冷 |

## 十、实装备注

### 10.1 状态互斥的实现约束

三者互斥是本系统的底层约束，建议以「同一生物同一时刻仅持有一个寒霜状态标签」的方式实现。任何施加操作前，先清除同级或低级状态，再写入目标状态，确保不会出现并存。

### 10.2 递进减速的实现参数

落霜的减速与化霜的加速为镜像关系，建议共用同一套「步长 + 上限 + 平滑回落」参数模型，便于平衡调试：

- 步长：每 25 刻变更一次。
- 上限：累计幅度 15%。
- 恢复：状态移除后按相同步长逐刻回调至 0。

### 10.3 归煦的时序

归煦包含两个关键时点，需在实现中严格区分：

1. **获得瞬间**：立即转化已有负面状态，并开启免疫。
2. **结束时刻**：正面效果开始独立计时。

两者不可合并，否则会出现正面效果时长被归煦持续时间吞掉的问题。
